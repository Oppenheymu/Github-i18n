Github-i18n

1.0.0

Translation happens entirely on your device: no network requests, no data collection. Switching takes effect immediately (the page reloads).

The dictionary covers some languages only partly: untranslated text stays in English.

Collects untranslated text on GitHub pages and keeps it on this device only. Off by default: nothing is collected before you turn it on.

The export may contain page text such as file and repository names — review it before pasting. No network requests are made at any point.

The dictionary keeps growing. Reports of missed or wrong translations are welcome in the repository.
